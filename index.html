Conexión con GitHub

El panel guarda y lee los datos en tu repositorio privado. Necesita un token de GitHub, que se guarda solo en este navegador.

¿Cómo creo el token?
  1. GitHub → tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nombre: panel. Expiración: 1 año. Repository access: Only select repositories → buscador_empleos.
  3. Permissions: Contents = Read and write, Actions = Read and write.
  4. Generate token, cópialo y pégalo aquí abajo.
